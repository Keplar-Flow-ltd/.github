Decent Work Initiative

Decent work is an engineering requirement

We run a Decent Work initiative at Keplar Flow. It asks one question: what does fair work look like now that software keeps doing more of the work?

The position

Automation changes jobs. We think it should change them for the better.

Every system we automate removes some tasks and reshapes others. We treat that as a design question and answer it before we build: what does this change mean for the people doing the work, and does it leave them better off? Technology should empower the person in the role. If a tool pushes them out of it, we redesign the tool. And when a contribution makes the work better, the value comes back to the person who made it.

What we stand for

The human back in the loop. People sit inside the operation, with the information and the authority to guide it.
Technology that empowers. Every tool we ship must leave a person more capable in their role.
Value that flows back. When a contribution improves the work, the person who made it sees that value return, directly and fairly.
